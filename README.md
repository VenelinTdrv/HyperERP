# Glam Ops Cloud

HyperERP
Разработваме ERP система за продажба основно на козметика.
Системата е web базирана, има ролеви достъп от инфлуенсъри и администратори.
Прилагам екран от системата.
Направи дизайна user friendly и спази всички добри практики за да е функционален екрана и приятен за очите на ползващите го.
